# mermaid-to-md-darwin-x64

Precompiled `mermaid-tui` binary for darwin-x64. This is an optional dependency
of [mermaid-to-md](https://github.com/pjsvis/mermaid-to-md) — you do not
install it directly; `npm install mermaid-to-md` pulls the right platform
package automatically.
